# pairwise-flow-field

百人同屏过桥，后排单位挤成一团原地转圈，桥塌后整群单位沿着旧流场跳崖：流场按格子积分，桥面格子和河面格子共用同一层成本，单位不知道桥已消失；积分场用四邻域，斜向移动绕远后单位在拐角来回抖；动态障碍只改成本不触发重建，单位沿旧路径直接走进新墙；流场异步重建时旧场还在被采样，半张新半张旧，方向出现断层；人群分离力按世界距离算，窄桥上左右推力把单位挤下桥；大体积单位只取中心格，身体跨两个格子时卡在门框；多层场景共用一张二维流场，地下通道单位往地面走；目标不可达时流场填最大值，单位朝最大梯度反方向乱跑；传送门两侧格子没连边，单位在门前堆积；流场分辨率 1 米，门口 0.5 米的缝隙被抹平；单位在流场更新中途切换目标，路径首尾不连续；浮点原点移动后格子坐标没重算，整群单位偏移半张图；桥塌事件和流场重建不在同一帧，单位有一帧按旧桥方向冲出去。gameplay/flow_field.py 是核心，tests/test_flow_field.py 15个红。要修的是：分层成本；八邻域积分；障碍重建；双缓冲；窄桥避让；多格占位；三维分层；不可达处理；传送门连边；分辨率适配；目标切换；原点换算；事件同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
